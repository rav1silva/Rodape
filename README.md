## Resumo

**Apresentamos o Rodapé! Uma plataforma desenvolvida para conectar pessoas através dos livros e facilitar a troca de obras entre leitores.**

O projeto consiste no desenvolvimento de um aplicativo mobile voltado para a troca de livros entre usuários. A proposta do Rodapé é criar uma comunidade onde leitores possam disponibilizar livros que já terminaram de ler e encontrar outras obras disponíveis para troca.

Por meio do aplicativo, os usuários podem visualizar livros disponíveis, cadastrar suas próprias obras e encontrar outros leitores interessados em realizar trocas. Dessa forma, o projeto incentiva a reutilização de livros, reduz o desperdício e facilita o acesso à leitura.

O Rodapé busca transformar livros que estão parados em estantes em novas oportunidades de leitura. Assim, uma obra que já foi lida por uma pessoa pode continuar circulando e proporcionando conhecimento, entretenimento e novas experiências para outros leitores.
